Privacy policy

Last updated November 15, 2026.

Mu is a private, internal tool. Data it reads stays in the copy of Mu that read it, on its owner's own computer or server.

Email

When a mailbox is connected, Mu asks for read-only access. It cannot send, change or delete email. It opens only order and shipping emails from suppliers, and emails forwarded to it on purpose, and keeps the order details from them (supplier, order number, items, tracking numbers) with a copy of the email. It does not open other email.

To read an email's text, Mu may use an AI model provider under terms that do not allow using it for training.

Google user data

Mu's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Mu does not use Google user data for advertising, does not sell it, and does not share it except as described above.

Removing access

Access can be removed at any time in Mu, or in the Google or Microsoft account's security settings.
